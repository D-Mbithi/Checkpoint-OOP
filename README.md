# Checkpoint OOP

A small web project demonstrating Object-Oriented Programming (OOP) principles using vanilla JavaScript, with a simple HTML/CSS user interface. This repository is a checkpoint assignment to practice designing and implementing classes, separating concerns, and interacting with the DOM.

---

## Features
- Core functionality implemented with JavaScript classes (encapsulation, methods, and simple state management).
- Clean HTML/CSS interface for interaction and visual feedback.
- Optional persistence with localStorage (save/load state).
- Modular structure suitable for extension and testing.

---

## Tech stack
- JavaScript (ES6+)
- HTML5
- CSS3

(Repository language composition: ~49% JavaScript, ~40% HTML, ~11% CSS)

---

## Quick start

1. Clone the repository
   git clone https://github.com/D-Mbithi/Checkpoint-OOP.git
2. Change into the project folder
   cd Checkpoint-OOP
3. Open the app in your browser:
   - Open index.html directly in a browser, or
   - Serve with a simple HTTP server (recommended):
     - Python 3: python -m http.server 8000
     - Node (http-server): npx http-server -c-1
   - Then visit http://localhost:8000 in your browser
